# Musab — Portfolio

A professional, recruiter-focused personal portfolio website built with vanilla HTML, CSS, and JavaScript. Free to host on Vercel.

## Features
- Sticky navigation with scroll-spy active link highlighting
- Responsive design (mobile + desktop)
- Scroll-reveal animations via IntersectionObserver
- Sections: Hero, About, Skills, Projects, Leadership, Contact

## Tech Stack
- HTML5 / CSS3 (vanilla, no framework)
- JavaScript (vanilla, no dependencies)
- Designed for Vercel / static hosting

## Deploy on Vercel (free)
1. Sign up at [vercel.com](https://vercel.com)
2. Install Vercel CLI (optional): `npm i -g vercel`
3. From this folder run: `vercel --prod`
4. Or drag-and-drop the folder into the Vercel web dashboard.

## Customization
- Replace `musab@example.com` in `index.html` with your real email.
- Update GitHub/LinkedIn URLs in the Contact section.
- Add more project cards under the `#projects` section.
- Update the Rotaract leadership details as needed.
